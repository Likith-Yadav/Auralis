# Auralis

An advanced YouTube Music client built with Material Design 3 for Android.

Auralis is designed to offer a premium, modern, and elegant music listening experience with Google's latest design guidelines (Material Design 3). It features a beautiful, clean UI, smooth transitions, and deep integration with YouTube Music.

---

## ✨ Key Features

- **Material Design 3 UI:** Sleek, modern, and clean visual design with lavender/purple dynamic colors.
- **Immersive Player:** Enjoy an immersive music listening experience with clean typography, dynamic backgrounds, and synchronized lyrics.
- **Smart Library Management:** Easily organize, filter, and access your playlists, downloaded songs, and cached files.
- **Advanced Customization:** 10-band equalizer, playback controls, gesture support, and device compatibility options (Chromecast & Bluetooth).
- **High-Quality Audio:** Optimized streaming quality tailored for various network speeds and devices.
